# NutriDay

Private nutrition diary web app built with Preact and Vite.

```bash
bun install
bun run dev
```

Open `http://localhost:1420/`. For deployment, run `bun run build` and publish `dist/` to a private HTTPS site. On iPhone, open that site in Safari and use **Add to Home Screen**.

Entries currently live in this browser's local storage. They do not sync or back up automatically.
